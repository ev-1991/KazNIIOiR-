KazIOR / КазНИИОиР — Отдел цифровизации, версия 2026

В комплекте:
- digital-ru.html — страница;
- css/digital-modern.css — весь дизайн и адаптивность;
- js/digital-modern.js — слайдер, мобильное меню, паутина, мягкая молния/импульс, команда и режим читаемости;
- img/ — логотип, hero-изображения и фотографии команды.

Что реализовано:
1. Современный адаптивный интерфейс без внешних CDN-зависимостей.
2. Автоматический слайдер: 7 секунд, кнопки, точки, свайп, пауза при наведении.
3. Спокойная интерактивная «паутина» по всей странице, реагирует на курсор.
4. Мягкая молния и круговой импульс при клике/тапе.
5. Современные карточки направлений и отдельный блок цифровых проектов.
6. Интерактивная команда: лёгкий 3D-эффект, подсветка курсора и выезжающий профиль.
7. Режим повышенной читаемости с сохранением выбора в браузере.
8. Контакты и ссылка на https://onco.kz/ru.
9. Авторство: Тимченко Евгений Юрьевич.
10. Адаптивность под телефон, планшет и компьютер.

Установка:
1. Сделайте резервную копию текущей папки digital на сервере.
2. Загрузите digital-ru.html, папки css, js и img с сохранением структуры.
3. Если страница лежит в /digital/, итоговый путь может быть /digital/digital-ru.html.
4. Никакой Bootstrap или внешний JavaScript для этой версии не нужен.

Локальная проверка:
- можно просто открыть digital-ru.html двойным кликом;
- либо в папке проекта выполнить: python -m http.server 8080
  и открыть http://localhost:8080/digital-ru.html

Примечание:
- ссылки в шапке — якоря текущей страницы плюс официальный сайт onco.kz;
- если нужно встроить полное многоуровневое меню действующего onco.kz, его можно вернуть отдельным этапом без изменения основных эффектов.
